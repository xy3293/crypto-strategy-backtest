### 1.2 严格的样本外单次触碰纪律 (One-Touch Only Rule)
为彻底杜绝数据窥探（Data Snooping）与多重假设检验陷阱，本调优协议规定：
- P2 样本外数据**仅允许触碰一次（touched exactly once）**，绝不进行事后二次调优或从 P1 重新遴选补充变体。
- 无论 P2 结果如何，失败即永久判定为 FAIL，禁止根据样本外表现调整网格边界或评价标准。

### 1.3 样本外验收标准 (Acceptance Criteria)
候选变体必须**同时严格满足**以下四项准则（原文载明），方可通过 P2 验证并晋级 Step 3：
> (a) P2 BTC+ETH Sharpe sum > default;
> (b) P2 BTC+ETH return sum > default;
> (c) per-coin P2 return no more than 5pp below default;
> (d) per-coin P2 max DD no more than 5pp deeper than default.

具体门槛定义：
- 准则 (a)：P2 期间双币夏普比率总和高于默认参数之和（`sharpe_sum(variant) > sharpe_sum(default)`）。
- 准则 (b)：P2 期间双币累计收益率总和高于默认参数之和（`return_sum(variant) > return_sum(default)`）。
- 准则 (c)：单币收益率相较默认参数落后不得超过 5 个百分点（`variant return >= default return - 0.05`）。
- 准则 (d)：单币最大回撤相较默认参数加深不得超过 5 个百分点（`variant maxdd >= default maxdd - 0.05`，即落后不超过 5pp）。

## 5. 深入机制诊断与调优总结 (Mechanistic Insights)

### 5.1 P1 样本内最优解为何在 P2 失效？
1. **Keltner 策略过拟合机制**:
   - 在 P1（牛市冲顶与暴跌熊市）中，将 EMA 从 35 缩短至 20 并将通道乘数扩大至 2.5～3.0，能有效过滤熊市反复假突破并捕捉短期大脉冲行情。
   - 但在 P2（2024 年至今的 ETF 牛市与结构化轮动）中，ETH 的走势表现为震荡上行且波动幅度受到压制。扩大的通道乘数（3.0）导致进场过迟，而缩短的均线（EMA 20）又导致离场过早，未能吃完整段波段，致使 ETH 收益率相较默认参数暴跌 11～20 个百分点。
   - 默认参数（`ema_period=35, multiplier=2.0`）虽然在 P1 收益看似平缓，但在不同市场状态下提供了更中庸平滑的滤波器，兼顾了波段捕捉与假突破防护。

2. **RSI 趋势策略过拟合机制**:
   - R1（`period=21`）在 P1 中因交易笔数过少（双币共 48 笔）而产生虚高的夏普（0.5790），进入 P2 依然受困于严重信号迟滞，双币收益与夏普均大幅跑输默认。
   - R2（`period=10, stop=1.0`）过于敏感，在震荡市场中频繁被 1.0 ATR 止损清出，导致 BTC 回撤大幅飙升至 -29.28%。

### 5.2 策略工程启示
- **参数孤岛效应**: 网格搜索找到的局部“极值点”通常是对过去特定波动率形态的过度记忆。
- **默认参数的鲁棒性**: 原始默认参数经受住了 2021–2026 全周期跨币种（BTC、ETH、SOL、BNB）的检验，且在 12 组单参数敏感性分析中（见 [VALIDATION.md](file:///home/hatch/workspace/crypto-strategy-backtest/results/VALIDATION.md)）表现出平滑的拓扑曲面与无符号反转特性，具备更扎实的统计稳健度。
